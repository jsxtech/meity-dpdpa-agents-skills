# MEITY DPDP Act — Examples, Scenarios & Templates

## Overview

This folder contains scenario walkthroughs, sector-specific guides, consent notice templates, and compliance tools for the **Digital Personal Data Protection Act, 2023 (DPDP Act)**.

Each example demonstrates how the agents and skills in this suite apply to real-world compliance situations.

## Governing Law

- **Digital Personal Data Protection Act, 2023** (No. 22 of 2023)
- **MeITY DPDP Rules, 2025 (Notified)** (gazetted November 2025)
- **Regulator:** Data Protection Board of India (DPBI)
- **Ministry:** MeITY — meity.gov.in

## Status Note

The DPDP Rules 2025 were gazetted in November 2025. Examples have been updated to reflect the final Rules. Legal counsel should be consulted for binding compliance decisions.
