# DPDP Act — Consent Notice Library

## Overview

Ready-to-use consent notice templates compliant with the **Digital Personal Data Protection Act, 2023**. Each notice covers the mandatory elements required under Sections 5–6 (consent) and Section 9 (children's data) of the Act.

## What Each Notice Includes

- **Data collected** — categories of personal data
- **Purpose of processing** — specific, itemised purposes
- **Data Principal rights** — access, correction, erasure, nomination (Sections 11–14)
- **Consent Manager** — how to manage or withdraw consent
- **Retention period** — how long data is kept
- **Grievance redressal** — contact details for complaints

## Usage

1. Copy the relevant template.
2. Replace placeholders (`[Organisation Name]`, `[Date]`, etc.) with your details.
3. Review with legal counsel before deployment.
4. Present the notice to Data Principals **before** collecting consent.
