# MEITY DPDP Act — Privacy Skills

## Overview

This folder contains a comprehensive suite of DPDP compliance skills for practitioners, DPOs, legal teams, product engineers, and compliance officers operating under the **Digital Personal Data Protection Act, 2023 (DPDP Act)**.

Each skill provides detailed capabilities, step-by-step execution guides, templates, checklists, and quick commands.

## Governing Law

- **Digital Personal Data Protection Act, 2023** (No. 22 of 2023)
- **MeITY DPDP Rules, 2025 (Notified)** (gazetted November 2025)
- **Regulator:** Data Protection Board of India (DPBI)
- **Ministry:** MeITY — meity.gov.in
